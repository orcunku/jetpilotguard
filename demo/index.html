How it decides

LAYER 01

Kalman filtering

Noisy altitude, g-force and perfusion signals are smoothed before anything downstream reads them.

LAYER 02 — advises

ML impairment model

A gradient-boosted classifier estimates G-LOC and disorientation risk. It can raise an advisory — but never seizes control.

LAYER 03 — overrides

Deterministic watchdog

Pure kinematics compute time-to-impact. Only this auditable, rule-based layer can trigger an Auto-GCAS override.
